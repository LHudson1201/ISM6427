# ISM6427

## Weather App

A simple, glass-style weather app built with plain HTML/CSS/JS and the free [Open-Meteo](https://open-meteo.com/) API (no API key needed). Default location is Boca Raton, FL; use the search bar to look up any city.

Files: `index.html`, `style.css`, `app.js`. No build step: on Netlify, deploy the repo root as-is (publish directory `.`, no build command).
